# 一、return语句
`return`语句用于从函数中返回，主要有两个作用：

1. **返回函数执行结果**（对有返回值的函数）
2. **终止函数执行**（对void函数或无返回值情况）
``return; // 无返回值（用于void函数）
``return expression; // 有返回值（用于非void函数）

```
注意：
（1）return只能返回一个值
（2）main函数的return：return 0代表正常结束运行，return 1返回错误代码
（3）确保函数在所有可能执行路径上都有return语句
```

## 1. 基本概念

**冒泡排序**是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。

**核心思想**：较大的元素会像气泡一样"浮"到数列的顶端，故名"冒泡排序"。

## 2.算法步骤
```
#include <stdio.h>

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {          // 外层循环：控制排序轮数
        for (int j = 0; j < n - i - 1; j++) {  // 内层循环：比较相邻元素
            if (arr[j] > arr[j + 1]) {         // 如果顺序错误
                // 交换元素
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

### 外层循环：n-1 次，内层循环：n-i-1 次
**总比较次数**：(n-1) + (n-2) + ... + 1 = n(n-1)/2

# 六、**strcmp 函数**
## 1.函数原型：
```
int strcmp(const char *str1, const char *str2);
```
## 2.功能说明

### 比较两个字符串的字典序（按ASCII码值比较）

## 3.比较规则

1. **逐字符比较**：从两个字符串的第一个字符开始比较
2. **遇到不同字符**：返回两个字符的ASCII码差值
3. **遇到'\0'结束**：如果所有字符都相同，返回0

## 4.返回值含义

- **< 0**：str1 < str2（str1在字典序中排在str2前面）
- **= 0**：str1 = str2（两个字符串完全相同）
- **> 0**：str1 > str2（str1在字典序中排在str2后面）
## 5.例子：
```
#include <stdio.h>
#include <string.h>

int main() {
    printf("strcmp(\"abc\", \"abc\"): %d\n", strcmp("abc", "abc"));     // 0
    printf("strcmp(\"abc\", \"abd\"): %d\n", strcmp("abc", "abd"));     
    // -1 ('c'=99, 'd'=100 → 99-100=-1)
    printf("strcmp(\"abc\", \"ab\"): %d\n", strcmp("abc", "ab"));       
    // 99 ('c'=99, '\0'=0 → 99-0=99)
    printf("strcmp(\"apple\", \"banana\"): %d\n", strcmp("apple", "banana")); // -1 ('a'=97, 'b'=98 → 97-98=-1)
    
    return 0;
}
```

# 七、strcpy函数
```
char *strcpy(char *dest, const char *src);
```
## 1.功能说明
`strcpy`函数将源字符串 `src`的内容（包括结束符 `\0`）复制到目标字符串 `dest`中。
## 2.参数说明
- `dest`：目标字符串的指针，必须指向足够大的内存空间
- `src`：源字符串的指针，要复制的字符串
##  3.工作原理

1. 从 `src`的第一个字符开始复制
2. 逐个字符复制到 `dest`，直到遇到 `src`的结束符 `\0`
3. 将 `\0`也复制到 `dest`
4. 返回 `dest`的地址
## 4.注意事项
### a. **内存安全问题**
### b.**字符串字面量问题**
```
// 错误示例：修改字符串字面量
char *dest = "Hello";   // 字符串字面量，存储在只读内存
char src[] = "World";
strcpy(dest, src);      // 运行时错误！试图修改只读内存

// 正确示例：使用字符数组
char dest[20] = "Hello"; // 字符数组，可修改
char src[] = "World";
strcpy(dest, src);      // 正确
```
### c. **重叠内存问题**
```
// 危险示例：源和目标内存重叠
char str[] = "hello";
strcpy(str + 1, str);   // 未定义行为！结果不可预测
```
## 5.相关函数比较

| 函数                         | 功能         | 安全性         |
| -------------------------- | ---------- | ----------- |
| `strcpy(dest, src)`        | 完整复制字符串    | 不安全，可能缓冲区溢出 |
| `strncpy(dest, src, n)`    | 最多复制 n 个字符 | 相对安全        |
| `strlcpy(dest, src, size)` | 指定目标缓冲区大小  | 最安全（非标准）    |

# 八、strcat函数（字符串连接）
```
char *strcat(char *dest, const char *src);
```
## 1.功能说明

### `strcat`函数将源字符串 `src`的内容复制到目标字符串 `dest`的末尾，覆盖 `dest`原来的结束符 `\0`，并在连接后的字符串末尾添加新的结束符 `\0`。

## 2.参数说明
- `dest`：目标字符串的指针，必须指向足够大的内存空间以容纳连接后的字符串
- `src`：源字符串的指针，要连接到 `dest`末尾的字符串

## 3.代码示例
```
#include <stdio.h>
#include <string.h>

int main() {
    char dest[20] = "Hello";
    char src[] = " World!";
    
    strcat(dest, src);
    printf("连接后的字符串: %s\n", dest);
    
    return 0;
}
输出：连接后的字符串: Hello World!
```

## 4.注意事项
### a. **内存安全问题**，要确保目标数组足够大
### b.**字符串字面量问题**
```
// 错误示例：修改字符串字面量
char *dest = "Hello";  // 字符串字面量，存储在只读内存
char src[] = " World!";
strcat(dest, src);  // 运行时错误！试图修改只读内存

// 正确示例：使用字符数组
char dest[20] = "Hello";  // 字符数组，可修改
char src[] = " World!";
strcat(dest, src);  // 正确
```

## 5.相关函数比较

|函数|功能|安全性|
|---|---|---|
|`strcat(dest, src)`|将 src 连接到 dest 末尾|不安全，可能缓冲区溢出|
|`strncat(dest, src, n)`|最多连接 n 个字符|相对安全|
|`strlcat(dest, src, size)`|指定目标缓冲区大小|最安全（非标准）|

# 九、strlen函数
```
size_t strlen(const char *str);
```
## 1.功能说明

`strlen`函数计算以空字符 `\0`结尾的字符串的长度，返回字符串中字符的个数（不包括结束符 `\0`）。

## 2.参数说明

- `str`：要计算长度的字符串指针

## 3.返回值

- 返回 `size_t`类型的值，表示字符串的长度（字符个数）

## 4.工作原理

1. 从字符串的起始位置开始遍历
2. 逐个字符计数，直到遇到字符串结束符 `\0`
3. 返回计数值（不包括 `\0`）
## 5.重要特性和注意事项

### 1. **不计算结束符**
### 2. **空字符串的长度为0**
### 3. **字符数组必须正确终止**
```
// 危险示例：缺少结束符
char bad_str[5] = {'H', 'e', 'l', 'l', 'o'};  // 没有'\0'
printf("长度: %zu\n", strlen(bad_str));  // 未定义行为！可能无限循环
```

## 6. 常见错误和陷阱

### 1. **未初始化的指针**
```
char *str;  // 未初始化
printf("长度: %zu\n", strlen(str));  // 未定义行为！段错误
```
### 2. **数组越界**
```
char str[5] = "Hello";  // 自动添加'\0'，但数组大小刚好 printf("长度: %zu\n", strlen(str));  // 正确，但数组大小紧张`
```
### 3. **修改字符串内容**
```
char str[] = "Hello";
str[1] = '\0';  // 插入结束符
printf("长度: %zu\n", strlen(str));  // 输出: 1 ("H")
```

## 7.相关函数比较

|函数|功能|返回值类型|
|---|---|---|
|`strlen(str)`|计算字符串长度|`size_t`|
|`sizeof(arr)`|计算数组大小|`size_t`|
```
char str[] = "Hello";
printf("strlen: %zu\n", strlen(str));  // 5 (字符个数)
printf("sizeof: %zu\n", sizeof(str));  // 6 (包括'\0'的总字节数)
```

# 十一、calloc（）函数
## `calloc()`函数是 C 语言中用于动态内存分配的重要函数，与 `malloc()`类似，但具有自动初始化为零的特性。

```
#include <stdlib.h> void *calloc(size_t num, size_t size);
```
## 1.参数说明

- `num`：要分配的元素个数
- `size`：每个元素的大小（字节）
- 总分配大小 = `num * size`

## 2. 基本用法
```
#include <stdio.h>
#include <stdlib.h>

int main() {
    // 分配能存储10个int的内存，并初始化为0
    int *arr = (int*)calloc(10, sizeof(int));
    
    if (arr == NULL) {
        printf("内存分配失败！\n");
        return 1;
    }
    
    // 验证内存已初始化为0
    for (int i = 0; i < 10; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);  // 所有元素都是0
    }
    
    free(arr);
    return 0;
}
```
## 3.calloc 与 malloc 的区别
### 3.1 初始化特性对比
```
#include <stdio.h>
#include <stdlib.h>

int main() {
    // malloc: 分配但不初始化（内容随机）
    int *arr1 = (int*)malloc(5 * sizeof(int));
    printf("malloc分配的内容（随机值）:\n");
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr1[i]);  // 输出随机值
    }
    printf("\n");
    
    // calloc: 分配并初始化为0
    int *arr2 = (int*)calloc(5, sizeof(int));
    printf("calloc分配的内容（全为0）:\n");
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr2[i]);  // 输出0
    }
    printf("\n");
    
    free(arr1);
    free(arr2);
    return 0;
}
```

3.2参数形式不同
```
// 等效的分配方式：
int *arr1 = (int*)malloc(10 * sizeof(int));  // malloc: 总大小
int *arr2 = (int*)calloc(10, sizeof(int));   // calloc: 元素个数 × 元素大小

// 两者分配的内存大小相同，但calloc会初始化为0
```
