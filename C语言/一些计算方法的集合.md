# 3.求最小公倍数

## 法一：**找到a,b中的较大值，假设是最小公倍数，然后去整除，不能整除就++，直到找到最小公倍数为止**
```
#include <stdio.h>
int main()
{
    int a,b;
    scanf("%d %d",&a,&b);
    int m=(a>b?a:b);
    while(1)
    {
        if(m%a==0&&m%b==0)
        {
            break;
        }
            m++;
    }
    printf("%d\n",m);
}
```

## 法二：使a* i %b == 0成立的a * i即为最小公倍数，i=0,i++

### 由a * i，a * i一定可以被a整除，由%b，a * i一定可以被b整除
```
#include <stdio.h>
int main()
{
    int a,b;
    scanf("%d %d",&a,&b);
    int i=1 ;
    while(1)
    {
        if(a*i%b==0)
        {
            break;
        }
            i++;
    }
    printf("%d\n",a*i);
}
```

# 4 .求最大公约数
## 法一：辗转相除法
### 第一步，先是两个数进行 模运算,来求余数   即 a%b
- ①当a可以被b整除时 （a%b == 0），直接返回 b , b就是最大公约数。例a = 4;b = 2; a%b== 0,所以b = 2,就是这两个数的最大公约数。
- ②当a%b != 0时，则进行辗转交换，这里用第三个变量来接收 c = a%b; 用 a 来接收 b的值,用b来接收c(余数的值)。
- **③重复上述①和②**
### 代码实现：
```
//求最大公约数  辗转相除法
#include <stdio.h>
int fun(int a,int b)
{
	while (a % b != 0)
	{
		int c = a % b;
		a = b;
		b = c;
	}
	return b;
}
int main() 
{
	int a = 0;
	int b = 0;
	scanf("%d %d",&a,&b);
	int ret = fun(a,b);
	printf("最大公约数为：%d",ret);
	return 0;
}
```

## 法二：辗转相减法
```
//更相减损法（辗转相减法）
#include<stdio.h>
int main() 
{
	int a = 0;
	int b = 0;
	scanf("%d %d",&a,&b);
	while (a != b) 
	{
		if (a > b)
			a = a - b;
		else
			b = b - a;
	}
```

```
将N个整数按从小到大排序的冒泡排序法是这样工作的：从头到尾比较相邻两个元素，如果前面的元素大于其紧随的后面元素，则交换它们。通过一遍扫描，则最后一个元素必定是最大的元素。然后用同样的方法对前N−1个元素进行第二遍扫描。依此类推，最后只需处理两个元素，就完成了对N个数的排序。
```

# 8. 二分求幂
## 核心理念：利用**分治思想**将幂次减半：
![[Pasted image 20251128084933.png]]

## 递归过程分析：
```
getPower(2, 10)
├── y=10 是偶数
├── res = getPower(2, 5)
│   ├── y=5 是奇数  
│   ├── res = getPower(2, 2)
│   │   ├── y=2 是偶数
│   │   ├── res = getPower(2, 1)
│   │   │   ├── y=1 是奇数
│   │   │   ├── res = getPower(2, 0) = 1
│   │   │   └── return 2 × 1 × 1 = 2
│   │   └── return 2 × 2 = 4
│   └── return 2 × 4 × 4 = 32
└── return 32 × 32 = 1024
```

## 例子：
```
int getPower(int x, int y) {
    if (y == 0)           // 基准情况：任何数的0次方等于1
        return 1;
        
    int res = getPower(x, y / 2);  // 递归计算 x^(y/2)
    
    if (y % 2 == 0)       // y为偶数
        return res * res;           // (x^(y/2))^2
    else                  // y为奇数  
        return x * res * res;       // x × (x^((y-1)/2))^2
}
```
