# 二、C语言数据类型转换详解

## 1. 数据类型转换概述

C语言中的数据类型转换分为两种主要类型：
- **隐式转换（自动转换）**：编译器自动进行的转换
- **显式转换（强制转换）**：程序员明确指定的转换

## 2. 隐式类型转换

### (1) 算术运算中的自动转换

```
#include <stdio.h> 
int main() { 
  int a = 10; 
  float b = 3.14; 
  double c = 2.5; 
  char d = 'A'; // ASCII 65 
  // 自动转换规则：小类型 → 大类型 
  double result1 = a + b; // int → float → double float 
  result2 = d + 1.5f; // char → int → float double 
  result3 = a * c; // int → double 
  printf("result1 = %.2f\n", result1); // 13.14 
  printf("result2 = %.2f\n", result2); // 66.50 
  printf("result3 = %.2f\n", result3); // 25.00 
  return 0; 
  }
```
### **自动转换等级（从低到高）

```
char → short → int → unsigned int → long → unsigned long → float → double → long double
```

## 3. 显式类型转换（强制转换）

### 4.类型转换要点：
1. **隐式转换**：编译器自动进行，遵循标准算术转换规则
2. **显式转换**：使用`(类型)`语法，明确转换意图
3. **精度损失**：大类型→小类型可能丢失数据
4. **符号问题**：有符号/无符号转换需特别注意
