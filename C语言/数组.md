# 1. 数组的基本概念

### (1) 什么是数组

数组是**相同类型元素**的集合，通过**统一的名字**和**不同的下标**来访问各个元素。

### (2) 数组的特点

- **相同类型**：所有元素必须是同一数据类型
- **连续内存**：<u>元素在内存中连续存储</u>
- **固定大小**：定义时确定大小，不能动态改变
- **下标访问**：通过下标（索引）访问元素，下标从0开始

# 2. 数组的声明和初始化

### (1) 基本语法
`数据类型 数组名[数组长度];`
### (2)初始化规则
```
int arr1[5]; // 未初始化，值是垃圾值 
int arr2[5] = {0}; // 全部初始化为0 
int arr3[5] = {1, 2}; // 前两个为1,2，其余为0 
int arr4[] = {1, 2, 3}; // 自动推断大小为3
```

# 3. 数组的访问和操作

### (1) 数组元素访问
```
int arr[5] = {10, 20, 30, 40, 50}; // 通过下标访问元素 
printf("第一个元素: %d\n", arr[0]); // 输出: 10 
printf("第三个元素: %d\n", arr[2]); // 输出: 30 
printf("最后一个元素: %d\n", arr[4]); // 输出: 50 

// 修改元素值 
arr[1] = 25; // 修改第二个元素 
arr[4] = 100; // 修改最后一个元素
```
### 注意：‘0’对应第一个元素

# 4.多维数组
## (1) 二维数组的声明和初始化
```
#include <stdio.h> 
int main() { 
// 1. 二维数组声明 
int matrix[3][4]; // 3行4列的矩阵 
// 2. 初始化方式 
int matrix1[2][3] = { {1, 2, 3}, // 第一行 {4, 5, 6} // 第二行 }; 
int matrix2[][3] = { // 自动推断行数 {1, 2, 3}, {4, 5, 6}, {7, 8, 9} }; 
int matrix3[2][3] = {1, 2, 3, 4, 5, 6}; // 线性初始化 return 0; }
```

## 如果需要遍历：
```
printf("二维数组遍历:\n"); 
for (int i = 0; i < 3; i++) { // 遍历行 
for (int j = 0; j < 4; j++) { // 遍历列 
printf("%3d", matrix[i][j]); } 
printf("\n"); }
```
