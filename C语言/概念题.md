- `i=j=10`等价于 `i=(j=10)`

## 5.C语言中的位运算符
| 运算符 | 名称   | 功能          | 示例                   |
| --- | ---- | ----------- | -------------------- |
| `   | `    | 按位或         | 对应位有一个为1则结果为1        |
| `&` | 按位与  | 对应位都为1则结果为1 | `1010 & 1100 = 1000` |
| `^` | 按位异或 | 对应位不同则结果为1  | `1010 ^ 1100 = 0110` |
| `~` | 按位取反 | 所有位取反       | `~1010 = 0101`       |
```
#include <stdio.h>

int main() {
    int a = 5;    // 二进制: 0101
    int b = 3;    // 二进制: 0011
    
    int result = a | b;  // 按位或运算
    // 0101 (5)
    // 0011 (3)
    // ------
    // 0111 (7)
    
    printf("%d | %d = %d\n", a, b, result);  // 输出: 5 | 3 = 7
    
    return 0;
}
```
